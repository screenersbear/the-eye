# The Eye

A notebook for planning and reflecting on shoots, on its own. The same app lives
inside Documenting Fictions (screenersbear.github.io/documenting-fictions/the-eye/).

The master copy is the suite: `Documenting Fictions/the-eye/`. Don't edit this
folder; edit the suite and copy it out with

    python3 tools/sync.py export the-eye

(run in the Documenting Fictions folder). That leaves out the suite's hook and gives
this copy its own storage (names starting df-theeye), so it never shares data with
The Eye inside the suite.
